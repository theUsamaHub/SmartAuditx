# Audit Module Implementation Plan

## Scope
Fix the options bug, align enums/models with AuditModule.md, build the audit assignment and auditor conduct workflow. No barcode scanning. No employee linkage (auditors are Users with Auditor role).

---

## Phase 1: Fix Options Bug + Align Enums/Models

### 1A. Fix options not saving in AddFieldAsync / UpdateFieldAsync
**File:** `Services/Implementations/AuditTemplateService.cs`

The `AddFieldAsync` (line ~394) creates the field with `Options = new List<AuditTemplateFieldOption>()` and ignores `model.Options`. Fix:
- After saving the field, iterate `model.Options` and create `AuditTemplateFieldOption` entities linked to the new field
- Same fix needed in `UpdateFieldAsync` — delete existing options not in the update list, create/update the rest

### 1B. Extend TemplateItemType enum
**File:** `Models/AuditModule/AuditEnums/TemplateItemType.cs`

Add missing field types. Keep existing numbering for backward compat:
```
Boolean = 1,     // Yes/No
Text = 2,        // Free text
Number = 3,      // Numeric value
Photo = 4,       // Image upload
Barcode = 5,     // Barcode scanner (skip for now per user request)
Selection = 6,   // Dropdown (single select) + Checkbox (multi select)
Rating = 7,      // Star/scale rating (1-5, 1-10)
Date = 8,        // Date picker
Signature = 9    // Signature pad
```

**Update JS** in `wwwroot/js/AuditTemplate/audit-template-builder.js`:
- Add new types to the `<select>` dropdown in Builder.cshtml modals
- Map new type IDs in `loadFields()` name mapping
- Show options group for type 6 (Selection) — both single and multi select use options
- Show min/max fields for type 7 (Rating)
- No special UI needed for Date (type 8) or Signature (type 9) in the template builder

### 1C. Update AuditStatus enum
**File:** `Models/AuditModule/AuditEnums/AuditStatus.cs`

Align with design doc. Renumber to match:
```
Draft = 1,
Scheduled = 2,       // Was "Assigned"
InProgress = 3,
Completed = 4,       // Was 5
UnderReview = 5,     // New
Approved = 6,
Cancelled = 7        // Was "Rejected"
```

Remove `OnHold` and `Rejected`. Add `UnderReview` and `Cancelled`.

### 1D. Add missing properties to AuditTemplateField
**File:** `Models/AuditModule/AuditTemplateField.cs`

Add properties that the design doc requires:
- `HelpText` (string?, max 1000) — guidance shown below the label
- `MinValue` (decimal?) — for Number/Rating fields
- `MaxValue` (decimal?) — for Number/Rating fields
- `AllowNotes` (bool, default true) — per-field notes box

### 1F. Fix AuditResponse to link to AuditTemplateField

Replace `AuditTemplateItemId` with `AuditTemplateFieldId` and add snapshot columns:

## Phase 3: Audit Assignment (Company Side)

### 3A. Create Audit Assignment ViewModels
**File:** `Models/ViewModels/AuditModule/` (new files)

Create:
- `AuditViewModel.cs` — for audit list/detail (Id, Title, TemplateTitle, Status, ScheduledDate, AssignedToUserName, FinalScore)
- `CreateAuditViewModel.cs` — for creating audit (TemplateId, Title, ScheduledStartDate, ScheduledEndDate, AssignedToUserId, BranchId)

### 3B. Create IAuditService + AuditService
**Files:** `Services/Interfaces/IAuditService.cs` + `Services/Implementations/AuditService.cs`

Methods:
- `GetAuditsByCompanyAsync(int companyId)` — list all audits for company
- `GetAuditByIdAsync(int auditId, int companyId)` — get single audit
- `CreateAuditAsync(CreateAuditViewModel model, int companyId, int userId)` — create audit from published template, snapshot version, set status to Scheduled
- `UpdateAuditAsync(...)` — update scheduled dates, reassign
- `DeleteAuditAsync(...)` — soft delete
- `GetAuditorsForCompanyAsync(int companyId)` — list users with Auditor role in same company (for dropdown)

### 3C. Create AuditController
**File:** `Controllers/mvccontrollers/AuditController.cs`

Actions:
- `Index` — list audits (GET, returns view)
- `List` — AJAX endpoint for audit table data
- `Get` — get single audit by ID
- `Create` — show create form (GET) + save (POST)
- `Edit` — show edit form (GET) + save (POST)
- `Delete` — delete audit
- `GetAuditors` — AJAX endpoint to get auditor list for dropdown

### 3D. Create Audit Views
**Files:** `Views/Audit/` (new folder)

- `Index.cshtml` — Audit list table (title, template, status, scheduled date, assigned auditor, actions)
- `Create.cshtml` — Create audit form (select template, enter title, set dates, select auditor from dropdown)

## Phase 4: Auditor Side

### 4A. Create Auditor Service
**File:** `Services/Interfaces/IAuditorService.cs` + `Services/Implementations/AuditorService.cs`

Methods:
- `GetAssignedAuditsAsync(int userId)` — list audits assigned to this auditor
- `GetAuditForConductAsync(int auditId, int userId)` — get audit with sections/fields loaded (verify assignment)
- `StartAuditAsync(int auditId, int userId)` — set status to InProgress, record ActualStartDate
- `SaveResponsesAsync(int auditId, int userId, List<AuditResponseViewModel> responses)` — save partial progress
- `SubmitAuditAsync(int auditId, int userId, List<AuditResponseViewModel> responses)` — save all responses, set status to Completed, record ActualEndDate, calculate score

### 4B. Expand AuditorController
**File:** `Controllers/mvccontrollers/AuditorController.cs`

Actions:
- `Index` — auditor dashboard (list assigned audits)
- `AssignedAudits` — AJAX endpoint for audit table
- `Conduct` — show audit form with all sections/fields (GET)
- `Start` — start the audit (POST)
- `SaveProgress` — save partial progress (POST)
- `Submit` — submit completed audit (POST)

### 4C. Create Auditor Views
**Files:** `Views/Auditor/` (expand existing folder)

- `Index.cshtml` — Dashboard with assigned audits table (title, template, status, scheduled date, actions)
- `Conduct.cshtml` — Audit execution page:
  - Load all sections and fields from the template
  - Render appropriate input for each field type:
    - Boolean → Yes/No toggle
    - Text → textarea
    - Number → number input
    - Rating → star rating (1-5 or 1-10 based on MinValue/MaxValue)
    - Selection (type 6) → radio buttons (single) or checkboxes (multi) based on field config
    - Photo → file upload
    - Date → date picker
    - Signature → signature pad (canvas-based)
  - Save Progress button (draft)
  - Submit button (final)

### 4D. Create Auditor JS
**File:** `wwwroot/js/Auditor/auditor-conduct.js`

- Initialize audit conduct form
- Handle save progress (AJAX POST)
- Handle submit (AJAX POST with validation of required fields)
- Signature pad implementation (simple canvas drawing)
